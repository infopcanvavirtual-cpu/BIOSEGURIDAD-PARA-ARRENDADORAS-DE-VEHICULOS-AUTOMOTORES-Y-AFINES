# Bioseguridad INFOP Virtual — Dashboard institucional v2.1

Proyecto piloto frontend estático. Conserva la navegación de la versión 2.0.

## Archivos oficiales pendientes

Colocar en `assets/images/` estos archivos (con estos nombres exactos):
- `banner-bioseguridad.jpg` — banner oficial del curso.
- `gobierno-honduras.png` — logo oficial del Gobierno de Honduras.
- `infop.png` — logo oficial de INFOP.

Si faltan, la portada muestra un reemplazo tipográfico y los logos no aparecen.

## Prueba

Abrir `index.html` con Live Server. Verificar menú, portada, secciones y versión móvil.

## Limitaciones

El porcentaje es demostrativo, no está conectado con Moodle. No hay registro de calificaciones ni autenticación. El iframe, la integración Moodle y la migración `.mbz` requieren pruebas posteriores.
